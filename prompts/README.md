# Prompt Templates — Financial Intelligence Platform

This directory contains Gemini prompt templates used by the backend AI layer.

## Files

| File                    | Purpose                                             |
|------------------------|-----------------------------------------------------|
| `coach_system.md`       | System prompt for the AI financial coach            |
| `categorisation.md`     | Batch transaction categorisation prompt             |
| `bias_analysis.md`      | Gemini-assisted bias analysis prompt (optional)     |
| `plan_generation.md`    | Gemini-assisted action plan generation (optional)   |

All templates use `{placeholder}` syntax for variable injection by `PromptBuilder`.
